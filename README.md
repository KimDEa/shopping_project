### 쇼핑몰 장바구니 & 할인 쿠폰 미니 프로젝트

### -흐름-
#### 판매상품 데이터 생성(원래 다른 파일에 생성후 모듈로 관리하려고 했으나 시간관계상 구현못함. 만약 구현 한다면 프로그램이 종료해도 재고를 관리 할수 있을것.) -> 할인상태, 결제완료 상태, 장바구니 배열을 생성자에 배치 -> 전체 메뉴에서 원하는 부분으로 이동(1.상품목록 2.담기 3.빼기 4.장바구니 5.쿠폰 6.결제 q.종료) -> 각 메서드로 기능 구현

### -대표적인 기능-
- 원하는 물건을 담을때 재고가 담고자 하는 갯수보다 많거나 이미 품절인 경우, 담을수 없다. 결제 후 재고가 0으로 되면 상태가 품절로 바뀐다.
- 장바구니에 담은 물건을 뺄때 원하는 물건을 삭제하거나 담은 갯수를 수정할수 있다.
- 장바구니에 담은 물건, 담은 갯수, 총 합계 금액을 볼수 있다.(쿠폰 적용 금액은 결제 하기전에 볼수 있다.)
- 쿠폰은 현재 나에게 적용 가능한 쿠폰만 출력이 되게 구현. 다만 기능적인 부분에서 시간 관계상 해결을 하지 못하여 기능이 정상적으로 작동이 안될 가능성 높음.(WIP)
- 결제를 하기전에 결제 정보가 영수증 형식으로 출력된다. 그안에 장바구니에서 볼수 있는 정보와 쿠폰 적용, 택배, 방문 수령에 따른 배송비 유무, 총 결제 금액에 대한 정보를 알수 있다.
- 결제를 완료 하면 상품목록에 있는 재고가 맞게 변하게 되고 장바구니는 자동으로 비워진다.
- 이미 사용한 쿠폰은 제외시키는 기능을 시간관계상 구현하지 못함.
- 메인 메뉴에서 q를 눌렀을때 종료하는 기능이 꼬여 정상적으로 작동하지 못함.
- 특정 메뉴안에서 0을 누르면 다시 뒤로가는 기능을 통일하여 구현하지 못함.
